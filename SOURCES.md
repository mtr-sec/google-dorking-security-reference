# Sources & Further Reading

## Primary source

- Google Dorks List: https://google-dorks.com/list/
  - The page states that it documents 200 patterns across ten categories.
  - Original category labels: Files & backups; Configuration; Directory listings; Logs & debug; Documents; Interfaces; Error output; Source control; Cloud storage; Public records.
  - The source page says each entry pairs a query shape with an explanation and remediation.
  - Consult the source page for its original query strings. This repository does not reproduce them verbatim.
